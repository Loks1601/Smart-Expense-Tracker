# 💰 SMART PERSONAL EXPENSE TRACKER
**CBSE Class 12 Informatics Practices (IP) / Computer Science (CS) Project**

---

## 📌 Project Overview
The **Smart Personal Expense Tracker** is a Python and SQLite-based desktop application developed with Tkinter. It empowers students and individuals to maintain financial discipline by tracking Income, Expenditures, Monthly Budgets, Financial Goals, Investments, and Bill Reminders with built-in visual analytics and intelligent insights.

---

## 🛠️ Software Stack
* **Programming Language**: Python 3.x
* **Database**: SQLite3 (Standard Python Library, zero setup needed)
* **GUI Toolkit**: Tkinter & TTK (Themed Widgets)
* **Visual Data Analytics**: Embedded Native Canvas Engine + Matplotlib support

---

## 🌟 Key Features
1. **Multi-Source Income Management**: Add, view, filter, and delete income records.
2. **Categorized Expenditure Tracking**: Track everyday expenses across categories with shop/merchant info.
3. **80% Budget Alert System**: Instant warnings when expense reaches or exceeds 80% of category budget.
4. **Savings & Goal Tracker**: Visual progress bars showing percentage completion toward saving targets.
5. **Investment Portfolio**: Track SIP, FD, Stocks, and Gold with auto-computed ROI%.
6. **Bill Reminders**: Track pending bills and due dates with overdue notifications.
7. **AI Spending Insights & Forecast**: Detects largest expense drain and forecasts next month's total expenditure.
8. **Gamified Financial Badges**: Unlocks badges like *"Saver of the Month"* based on savings ratios.
9. **One-Click Demo Seeder**: Instantly populates realistic test data for Viva demonstrations.
